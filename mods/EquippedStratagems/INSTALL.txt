EquippedStratagems - revision 9

Exports your selected and mission-granted stratagems, one name per line, to:
%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\EquippedStratagems.log

This build reads the LOCAL player's loadout every 0.5 seconds. On the selection
screen it exports your chosen slots. In mission it reads the live player payload,
including Reinforce, SOS Beacon, Resupply and granted equipment/objectives.
Grants update as they enter or leave that payload. No Ctrl/menu key is required.
Empty entries and duplicate names are omitted. By default, active cooldown and
delivery timers remove names until they expire. This does not check every use
restriction (for example jamming or depleted charges). A prior selection-screen capture
is not required in mission. A game restart clears old output. A transient read
failure retains the last valid list and records the reason in diagnostics.

Revision 6 gates SEAF Artillery on the game's artillery controller: ammunition
must be enabled and remaining, and its artillery unit valid. Merely having the
SEAF entry in mission data does not export it. Missing/unreadable SEAF state
omits SEAF only. This gate applies with cooldown filtering ON or OFF.
Revision 7 also gates Upload Data on the game-maintained local in-range flag
and objective eligibility flags. Missing/unreadable upload state omits Upload
Data. Eagle Rearm now requires spent Eagle uses, including upgraded capacity.
Revision 9 reads Hellbomb eligibility from the native HUD membership state. Unreadable or mismatched HUD data omits Hellbomb. The portable Hellbomb is unaffected.

Optional dependency: CowboyBingus ModOptionsMenu v1 API.
In Escape > MODS > EquippedStratagems, press APPLY after changing:
  Hide Stratagems on Cooldown (default ON)
  Include Mission Grants (default ON)
  Update Frequency (0.25 / 0.5 / 1 second; default 0.5)
Without ModOptionsMenu, these defaults still work automatically.
https://github.com/CowboyBingus/ModOptionsMenu

The updated wheel reads EquippedStratagems_state.log first. This companion file
has a complete-snapshot marker and count, so an empty list clears the wheel
and a concurrent partial read retains its previous list. EquippedStratagems.log
continues to contain only names for compatibility. Restart the wheel application
after updating its source. Source changes do not update a separately packaged EXE.

1. Close Helldivers 2.
2. Replace the old EquippedStratagems entry in your mod manager with this ZIP.
   Keep Bingus Shared Loader enabled. Mod Bindings Menu is optional, for the
   existing Send Strategems key. Do not deploy two copies of this addon.
3. Deploy and relaunch. On mission selection, choose a known set of stratagems
   and leave the screen open for a second. Inspect EquippedStratagems.log.
4. Deploy into the mission and check that granted stratagems join the list.
5. Use a stratagem: it should disappear during its timer and return at expiry.

Names use the wheel's catalog spelling. They are resolved from each selected
StratagemInfo definition's input sequence, not the outdated debug-name table.
The catalog covers 113 unambiguous codes plus the verified Upload Data definition.
Unsupported codes clear the export
and report an error rather than exporting a partial list or a guessed name.

Diagnostics (separate from the names-only output):
  EquippedStratagems_diagnostics.log - capture status, IDs, codes and names

Reader layout is pinned to game.dll PE timestamp 1790161983. An unsupported
game build is reported rather than scanned heuristically. Other players' cards,
payload mismatches and data changing during a read are rejected and retried.
Failed writes/flushes/closes are retried. Send Strategems forces a rewrite.

Upstream loader installation information:
https://github.com/CowboyBingus/BingusSharedLoader/releases/latest

Revision 9: Hellbomb now follows native HUD membership (card +0x36F0), matched to its current payload index and kind. The game updates this state with the menu closed too; the exporter samples it at the configured interval instead of duplicating objective/proximity scans. No verified game event subscription is available, so polling remains. File writes occur only on content changes (or explicit refresh). Local regression tests cover availability transitions, stale HUD data, and portable Hellbomb isolation; live validation is pending.
