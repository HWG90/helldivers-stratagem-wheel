EquippedStratagems

Writes the currently equipped stratagems, one catalog name per line, to:

%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\EquippedStratagems.log

The file is rewritten when that loadout changes, and again when the
Send Strategems binding fires. Install this zip next to Bingus Shared Loader
and Mod Bindings Menu. The loader discovers the plaintext entry
mods/EquippedStratagems/EquippedStratagems. If mods/codex/loadouts is
already loaded and holds one catalog-name array, that array is written.
Otherwise the mod reads game.dll the same way BetterStratagemBounce and
ReinforcementBeaconsFixed do: GetModuleHandleA and ReadProcessMemory.
Local player *(game+0x3326468), StratagemInfo *(game+0x348e8f8),
equipped rows *(game+0x33266b0). Names go through
CowboyBingusModLoader.open_log. It registers Send Strategems with
ModBindingsMenu.register_binding. It does not patch code or hide itself.

1. Close Helldivers 2. Use one mod manager, Arsenal or HD2MM.
2. Import Bingus Shared Loader v15 or newer (v18 is the current API 1 release),
   Mod Bindings Menu v2, and EquippedStratagems.zip.
3. Enable all three. With Arsenal's default priority, put Bingus Shared Loader
   last. If first-mod priority is on, put the loader first.
4. Purge / Deploy, then launch the game normally.
5. Check %LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\BingusSharedLoader.log
   for this line:

   mods/EquippedStratagems/EquippedStratagems: loaded

6. On the MODS tab, bind Send Strategems. That key is stored by Mod Bindings
   Menu, not by a separate settings file.

A list that does not match the catalog leaves the previous log in place.
If the player state is unreadable, the stratagem wheel keeps Learn and Scan.
